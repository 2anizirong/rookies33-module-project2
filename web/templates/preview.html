URL 미리보기 (SSRF 실습)

URL을 입력하면 서버가 대신 요청해서 응답을 보여줍니다. 외부 페이지 프리뷰 기능이라고 생각하세요.

여기서 정한 레벨이 서버에 저장되어 모든 요청에 동일하게 적용됩니다. (중첩 요청·자기 경유 포함 — 바깥/안쪽이 항상 같은 레벨) 현재 레벨: {{ level }}

보안을 위해 127.0.0.1, localhost, 169.254.169.254는 차단됩니다.

💡 실습 힌트 - 차단된 호스트를 다른 방법으로 표현하기

같은 IP 주소를 여러 형식으로 표현할 수 있습니다. 아래 링크는 현재 설정된 보안 레벨({{ level }})로 시도됩니다.

127.0.0.1 (loopback)

  • 일반: http://127.0.0.1:5001/...
  • 10진수: http://2130706433:5001/...
  • 16진수: http://0x7f000001:5001/...
  • 8진수: http://0177.0.0.1:5001/...
  • 단축: http://127.1:5001/...

169.254.169.254 (AWS 메타데이터)

  • 일반: http://169.254.169.254/...
  • 10진수: http://2852039166/...
  • 16진수: http://0xa9fea9fe/...
  • * 이 앱에서는 metadata_server.py를 5001 포트로 실행해서 실습합니다.

추가 실습

  • file:// 스킴: file:///etc/passwd (Linux)
  • file:// 스킴: file:///C:/Windows/win.ini (Windows)

🔎 레벨별로 이렇게 동작합니다

  • Level 0: 필터 없음 → 직접·모든 인코딩 성공
  • Level 1: 문자열 블랙리스트 → 일반 표기만 차단, 10/16/8진수·단축 우회
  • Level 2: 부분 정규화 → 일반+10진수 차단, 16/8진수·단축 우회
  • Level 3: 완전 방어 → 모든 인코딩 차단

🎯 최종 목표

5001 포트에서 실행 중인 가짜 AWS 메타데이터 서버의 IAM credentials를 SSRF로 탈취하세요.
